02. About This Page

This page is a full-stack project: a static frontend with zero flag logic in the browser, backed by serverless API endpoints. Flags are stored server-side only as salted SHA-256 hashes (unique random salt per challenge) and every submission is verified with a timing-safe comparison.

  • Submissions are rate-limited to keep brute-forcing impractical.
  • Oversized or empty input is rejected before any hashing happens.
  • Failure responses are generic — a wrong flag and an unknown challenge look identical.
  • Writeups unlock only after the server confirms a correct flag — never bundled in advance.

Stack: static HTML/CSS/JS frontend · Netlify Functions (Node.js) + Netlify Blobs backend · SHA-256 + per-challenge salts · challenges managed from the site admin panel (draft/publish, file attachments, gated writeups) · fetch-based flag submission.
